# 个性化配置指南

直接复制默认规则通常会失败。建议先用自己的历史直播完成一轮标注，再调整代码。

## 必须重新标注的内容

### 表情与笑声

`program_rule_engine_v2.py` 中的 `LAUGHTER_SIGNAL_PATTERN` 包含中文笑声、数字梗、文字表情和直播间表情 ID。表情 ID 只表示当前观众把这些表情当作笑声使用，换直播间后含义可能完全不同。

先统计高频表情，再人工抽查其上下文。不要把所有方括号表情都视为笑声。

### 主题名称

`program_source_analysis.py` 中的 `THEMES` 是当前直播间的栏目词典：猎人、Boss/英雄、爽局、自私、内鬼、理财。其他游戏、主播或语言环境应删除或替换这些主题。

每个主题参数依次是：关键词、聚类间隔、最短持续时间、最少消息数、最少用户数、前置时间。

### 普通流程和无效复读

`ROUTINE_PATTERN`、`INVALID_ECHO_TERMS` 与 `PLACEHOLDER_PATTERN` 用于排除开播、下播、卡顿、礼物、固定口号和纯占位表情。它们高度依赖直播间文化。

### 时间约定

当前接口适配层把早上 7 点作为直播日分界，用于汇总片段和本地 P 号。迁移到其他频道时应先确认录制文件名和直播日约定。

## 建议的校准流程

1. 随机抽取至少 10 场直播，人工标注候选开始、实际效果结束和误报区间。
2. 统计笑声词、表情 ID、主题词和普通流程词的出现频率。
3. 先调独立用户数和密度阈值，再调关键词；不要用大量关键词弥补用户证据不足。
4. 分开评估“找到片段”和“确定结尾”，避免为了减少漏检再次拖长尾部。
5. 对单平台、双平台、断流、多 P、弹幕稀疏场次分别验证。
6. 保留人工审计样本，记录每次规则变化造成的新增、删除和边界移动。

## 抖音旁路配置

复制 `examples/douyin.example.json` 到工作目录的 `config/douyin.json`，填写同一直播间 URL 和弹幕目录。不要提交真实账号凭据或私有接口信息。

只有时间戳和房间一致的旁路弹幕才应参与对齐。几秒的平台延迟通常可接受，但长延迟、回放弹幕和客户端重发仍可能污染边界。
