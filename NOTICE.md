# Third-party tools

This repository does not vendor the following projects:

- [biliup](https://github.com/biliup/biliup), used by the production workflow for recording and uploading. biliup is distributed under its own license.
- [FFmpeg](https://ffmpeg.org/), used for media processing and inspection.
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper), optionally used for speech-boundary refinement.

Users must install and comply with each dependency separately.
